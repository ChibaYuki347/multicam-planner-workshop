# 03. 参加者向け事前準備

## 全員

- GitHub Copilot が使える状態にしておく (個人ライセンスまたは組織ライセンス)。
- 当日のオンライン会議ツールに接続できる端末を 1 台用意する。
- ワークショップ開始 10 分前にログインしておく。

## ナビゲーター (画面共有して Copilot を動かす人)

1. Node.js 20 以上、npm 10 以上をインストールする。
2. VS Code (または Copilot 対応の任意の IDE) をインストールする。
3. 本リポジトリを clone する。
4. プロトタイプ雛形が動くことを確認する。

   ```bash
   cd prototype
   npm install
   npm run dev
   # http://localhost:3000 を開いてカメラ一覧が表示されることを確認
   ```

5. Copilot Chat を開いて、`prototype/lib/types.ts` を選択しながら「このファイルの目的を 3 行で説明して」と聞き、応答が返ることを確認する。

## ビジネスレビュアー

- 自分が担当する現場で「マルチカメラ撮影の設置設計」に近いシーンで困ったこと、顧客から受け取った要望、よく聞かれる質問を 1 〜 3 個メモしてくる。
- 端末の準備は閲覧のみで構わない。

## 開発レビュアー

- TypeScript と React の基本 (関数コンポーネント、useState 程度) を読める状態にする。
- ナビゲーターと同じ環境を持っておくと、サブで実装に入れて便利。

## オブザーバー

- ワークショップ全体を観察し、組織に持ち帰る学びを言語化する係。
- 進行中は手を動かさず、メモに専念して構わない。

## トラブルシューティング (事前確認用)

- `npm install` が遅い場合: ネットワークやプロキシ設定を確認する。
- ポート 3000 が使えない場合: `PORT=3100 npm run dev` のように起動する。
- Copilot Chat が反応しない場合: VS Code を再起動し、Copilot 拡張のサインインを確認する。
