# 01. 題材: マルチカメラ撮影プランナー

## ストーリー（架空）

ある撮影スタジオでは、舞台 / イベント / 配信などで複数台の IP 制御カメラを同時に使う機会が増えている。カメラはネットワーク経由でパン・チルト・ズームを制御でき、被写体ごとに「センターのヘッドショット」「下手の人物の引き」のような撮り方を割り当てる。

現状は、各カメラの設定をプルダウンや数値入力で個別に行うコントロールアプリしかなく、

- どのカメラがどの被写体を、どんな構図で撮るのか
- ステージのどの位置に立つと、どのカメラに映るのか
- 俯瞰カメラの死角はどこか

を **設置前に視覚的に確認できない** ことが、現場担当者・撮影ディレクター双方にとって負担になっている。

ワークショップでは、この負担を下げる「マルチカメラ撮影プランナー」というツールを、3 時間で一緒に設計・実装していく。

## 想定ユーザー

| ロール | 関心事 |
|---|---|
| 撮影ディレクター | 撮りたい絵を、現場に行く前に確認したい |
| 現場オペレーター | 設置と動作確認を最短で済ませたい |
| 営業 / 提案担当 | 顧客に対して「こう撮れます」を分かりやすく見せたい |
| 製品マネージャー | 設置設計の手間を理由にした失注 / 解約を減らしたい |

## スコープ

- ステージ、被写体、メインカメラ、俯瞰カメラを **上面図 (2D)** で配置する。
- 各カメラに「撮影意図 (intent)」をひも付け、選択時に一覧表示する。
- 配置と意図を 1 つの「シーン」として保存・読み込みできる、最小限の永続化を扱う（プロトタイプではメモリのみで OK）。

## 対象外

- 3D ビュー、物理シミュレーション
- 実機カメラへの実コマンド送出
- マルチユーザー同時編集

## 用語

| 用語 | 意味 |
|---|---|
| Stage | 撮影対象が立つ領域。長方形で表す |
| Subject | 被写体。座標と表示名を持つ |
| Camera | メインカメラ。座標、向き、画角、担当被写体、撮影意図を持つ |
| Overhead Camera | 俯瞰カメラ。座標と視野範囲を持つ |
| Shot Intent | 「下手のヘッドショット」など、撮影意図を自然言語で表現したもの |
| Scene | 上記をまとめた 1 つの構図 |
