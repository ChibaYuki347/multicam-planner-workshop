# 06. 最短ルート: sdd-guide で 1 文から仕様までを 1 つの会話で

このリポジトリの **入口** は 1 つです。VS Code Copilot Chat で `sdd-guide` カスタムエージェントに切り替えて、現場の困りごとを 1 文書いてください。

```
カメラの設置設計が現場で大変。
```

これだけで、エージェントが次の 5 ステップを順に進め、毎ステップで承認を取ります。

```
1. ユーザーストーリー 3 本生成 → 1 本選ぶ
2. 仕様化 + 業務観点セルフレビュー → exercises/02-spec.md へ保存
3. 単一 HTML モック生成 → mockups/<slug>.html へ保存
4. 実装計画 (タスク順) → exercises/03-implementation-plan.md へ保存
5. タスク 1 件を Copilot Chat 用作業指示に整形
```

## 3 つの使い方ルート

| ルート | こんなときに | 使うもの |
|---|---|---|
| **最短** | ワークショップ当日、まずここから | `sdd-guide` カスタムエージェント |
| **手動** | 1 ステップだけ走らせたい / プロンプトを覚えたい | `/sdd-user-story` 〜 `/sdd-task` (スラッシュコマンド × 6) |
| **CLI** | エディタを開かずに半自動で回したい | `copilot --agent .github/agents/spec-loop.agent.md "..."` |

詳しい使い分けは `docs/04-custom-prompts-and-agents.md` (リファレンス) を見てください。

## 最短ルートの使い方

1. **VS Code を開く** (1.95 以降推奨)。本リポジトリをそのまま開いてください。
2. **GitHub Copilot Chat を開く** (左サイドバー or Cmd/Ctrl+Alt+I)。
3. **モデルセレクタの右にあるエージェントピッカー** から `sdd-guide` を選びます。
4. **チャット欄に困りごとを 1 文** だけ書いて送信します。
   ```
   カメラの設置設計が現場で大変。
   ```
5. エージェントが順に提案してきます。各ステップで次の 3 択で返してください。
   - `OK` → 次のステップへ
   - `修正: <内容>` → 指示を反映して同じステップをやり直す
   - `スキップ` → 次のステップへ飛ぶ
6. 5 ステップが終わると、Copilot Chat に貼れる作業指示が出力されます。
7. その作業指示をコピーし、`prototype-builder` カスタムエージェントに切り替えて貼り付けて実装してもらいます。
8. 実装結果を `business-reviewer` カスタムエージェントでレビューします。

```
[あなた]
   │  困りごとを 1 文
   ▼
┌─────────────────────────────────────────┐

│                                         │
│  US 3 本 ──選択──▶ 仕様 ──セルフレビュー▶ 仕様改訂  │
│                          │                       │
│                          ▼                       │
│                       モック (HTML)              │
│                          │                       │
│                          ▼                       │
│                       実装計画                   │
│                          │                       │
│                          ▼                       │

              │
              ▼

```

## 出力物の置き場所

`sdd-guide` は、毎ステップで上書き確認を取った上で次のファイルに書き出します。

| ステップ | 出力先 |
|---|---|
| 1. US | `exercises/01-user-stories.md` (追記) |
| 2. 仕様 | `exercises/02-spec.md` |
| 3. モック | `mockups/<slug>.html` |
| 4. 実装計画 | `exercises/03-implementation-plan.md` |
| 5. 作業指示 | チャットに表示 (手動でコピー) |

## 既存のスラッシュコマンドとの関係

| スラッシュコマンド | sdd-guide での対応ステップ |
|---|---|
| `/sdd-user-story` | 1 |
| `/sdd-spec` | 2 |
| `/sdd-mockup` | 3 |
| `/sdd-plan` | 4 |
| `/sdd-task` | 5 |
| `/sdd-business-review` | 2 のセルフレビュー (自動実行) |

「ステップを 1 つだけ手動で走らせたい」場合や「sdd-guide の出力を 1 ステップだけやり直したい」場合に、スラッシュコマンドを単発で使ってください。

## トラブル時

- **エージェントが想定外の返答をする**: 「ステップ N の出力フォーマットに従って」と短く伝えるか、`修正: ...` で具体的に書いてください。
- **会話が長くなって混乱した**: ステップ完了時点の `exercises/02-spec.md` などを開いて、そこから新しい会話で `spec-author` カスタムエージェントに引き継いでください。
- **Copilot のクォータが枯渇した**: `docs/05-backup-byok.md` の手順で Azure OpenAI BYOK に切り替えてください。BYOK 後でも `sdd-guide` はそのまま動きます。
- **CLI で半自動的に回したい**: 別経路として `copilot --agent .github/agents/spec-loop.agent.md "..."` も同じ題材で動きます。エディタが要らない場面向けです。
