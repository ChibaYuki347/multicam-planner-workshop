# 00. ワークショップの全体像

## ねらい

GitHub Copilot を使った仕様駆動開発を、ビジネスロールと開発ロールが同じ部屋で 180 分の中で体験すること。

最終的なソフトウェアを作り切ることが目的ではなく、**「曖昧な要望 → ユーザーストーリー → 仕様 → 実装計画 → プロトタイプ → レビュー」** のサイクルを共有することが目的。

## 体験してもらう 3 つのこと

1. **仕様を Copilot と作る**
   - ビジネスロールが日常言葉で要望を出し、Copilot がユーザーストーリーと受け入れ条件に整形する。
2. **実装を Copilot に任せ、レビューで品質を担保する**
   - 仕様 → 実装計画 → タスク → 実装の流れを 1 サイクル回し、結果をビジネスロールがレビューする。
3. **複数人で AI コーディングを回す型を試す**
   - 同じ題材を全員でいじるのではなく、役割を分けて「考える人 / 実行する人 / レビューする人」を決めて回す。

## 当日の到達ライン

- ユーザーストーリーを 1 〜 3 本確定する
- そのうち 1 本を仕様化し、実装計画に落とす
- フロントエンド中心の簡易プロトタイプを 1 サイクル分動かす
- ビジネスロールが触ってフィードバックを返し、Copilot で 1 ターン改善する

## 対象外

- 本番 API への接続、認証、CI/CD パイプライン、E2E テスト整備、デプロイ
- 3D 表示、物理的に正確な画角計算、実機カメラ連携
- 製品としての完成度や保守性
